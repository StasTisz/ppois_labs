## 🛠 Технологический стек

* **Языки реализации:**
  * **C++ (Лабораторные 1, 4):** Выбран для низкоуровневого управления памятью, перегрузки операторов и обобщенного программирования, что органично соответствует требованиям заданий.
  * **Python (Лабораторные 2, 3):** Применяется для проектирования масштабных доменных моделей (более 50 классов) и реализации сложных объектно-ориентированных архитектур, где критически важна скорость связывания бизнес-логики и читаемость кода.

* **Тестирование:** Для Python используется `pytest` с плагином `pytest-cov` (строгое требование покрытия кода **>90%**). Для С++ применяется фреймворк `Google Test`.
* **Контроль качества:** `ruff` (линтер) и `mypy` (статический анализатор типов).
* **CI/CD:** GitHub Actions. Пайплайн автоматически запускает тесты, проверяет покрытие, анализирует стиль и собирает независимый исполняемый артефакт в раздел Releases.

## ⚙️ Принципы разработки и архитектуры

* **Консольный интерфейс (CLI):** Каждая лабораторная имеет независимый CLI, демонстрирующий ключевые поведения предметной области (без привязки к IDE).
* **Чистота репозитория:** В историю коммитов попадает строго исходный код. Все артефакты сборки, кэш и конфигурации редакторов исключены с помощью `.gitignore`.
* **Изоляция изменений:** Прямые коммиты в `main` не производятся. Разработка ведется в отдельных `feature`-ветках с последующим слиянием через Pull Request.

## 🚀 Запуск и проверка

Проект полностью отвязан от конкретной среды разработки и собирается из консоли. 

Детальные инструкции по локальному запуску, сборке и спецификации классов для каждой отдельной работы находятся во вложенных файлах `README.md` внутри папок `labX/`.

## 🔬 Лабораторная работа №1: Основы ООП (Класс)

### Реализованный функционал

1. **Класс `Polynomial` (Многочлен):**
   - Хранение коэффициентов в векторе с автоматической нормализацией (удаление старших незначащих нулей).
   - Перегрузка арифметических операторов: `+`, `-`, `*`, `/` (деление уголком), `+=`, `-=`, `*=`, `/=`.
   - Вычисление значения многочлена в точке $P(x)$ через `operator()`.
   - Доступ к коэффициентам через `operator[]`.
   - Сравнение (`==`, `!=`) и потоковый ввод-вывод (`<<`, `>>`).

2. **Шаблонный класс `Set<T>` (Канторовское множество):**
   - Хранение уникальных элементов заданного типа.
   - Операции над множествами: объединение (`+`), пересечение (`*`), разность (`-`).
   - Построение булеана (множества всех подмножеств) с помощью метода `powerSet()`.
   - Проверка вхождения, добавление, удаление элементов.
   - Потоковый ввод-вывод в формате `{a, b, c}`.

3. **Документация и архитектура:**
   - Интерактивное консольное меню (CLI) полностью отделено от бизнес-логики.
   - Код документирован с использованием стандарта **Doxygen** (`@brief`, `@param`, `@return`, `@throw`).
   - Написаны unit-тесты с использованием **Google Test** (покрытие кода более 90%).

## 🛠 Сборка и запуск

Проект использует систему сборки CMake и не привязан к конкретной IDE.

### 1. Сборка основного приложения (CLI)
```bash
cd lab1
cmake -B build
cmake --build build --target ppois_lab1
./build/ppois_lab1
```

### 2. Сборка и запуск Unit-тестов
```bash
cmake --build build --target run_tests
./build/run_tests
```

## 🚀 CI/CD и автоматизация

Проект интегрирован с **GitHub Actions**. При каждом обновлении веток автоматически выполняются:
- **Статический анализ кода:** проверка линтером `cppcheck`.
- **Сборка проекта:** проверка компиляции под Linux (Ubuntu).
- **Тестирование:** запуск unit-тестов.
- **Анализ покрытия:** сбор метрик с помощью `lcov`.
- **Релизы:** автоматическая сборка и публикация исполняемого артефакта в разделе **Releases** на GitHub.

## 📚 Documentation

The `docs/` folder is a build artifact and **is generated by the user**. The repository maintains only the `Doxyfile` configuration and Doxygen-formatted source code comments.

### Guide to Generating Documentation:

1. Ensure the Doxygen utility is installed on your system:
   - **macOS:** `brew install doxygen`
   - **Linux (Ubuntu/Debian):** `sudo apt install doxygen`
   - **Windows:** Download the installer from the official Doxygen website.
2. Open a terminal and navigate to the directory of the first laboratory work:
   ```bash
   cd lab1
   ```
3. Run documentation generation using the configuration file:
   ```bash
   doxygen Doxyfile
   ```
4. The tool automatically generates the `docs/` directory. Open the documentation index in your browser:
   ```bash
   open docs/html/index.html
   ```

## Class Features & Capabilities

### Polynomial
- Storage of polynomial coefficients in a vector with automated normalization (trimming leading insignificant zeros).
- Overloaded arithmetic operators: `+`, `-`, `*`, `/` (polynomial long division), `+=`, `-=`, `*=`, `/=`.
- Evaluation of polynomial value at point $P(x)$ via `operator()`.
- Coefficient access via `operator[]`.
- Equality comparison (`==`, `!=`) and stream I/O (`<<`, `>>`).

### Set<T> (Cantor Set)
- Storage of unique elements of a specified type.
- Set operations: union (`+`), intersection (`*`), difference (`-`).
- Power set generation (set of all subsets) via the `powerSet()` method.
- Membership check, element insertion, and element removal.
- Stream formatting and I/O in standard `{a, b, c}` notation.

## Building the Project

The project is built via **CMake**.

**Linux / macOS:**
```bash
cd lab1
cmake -S . -B build
cmake --build build
```

**Windows (Visual Studio / MSVC):**
```powershell
cd lab1
cmake -S . -B build
cmake --build build --config Release
```

## Running the Console Application

The entry point and interactive menu are located in the `app/` module. After building, run the compiled binary:

**Linux / macOS:**
```bash
./build/lab1_app
```

**Windows:**
```powershell
.\build\Release\lab1_app.exe
```

## Testing

The project is covered by automated unit tests using **Google Test**. Execute all test suites with:

```bash
./build/lab1_tests
```

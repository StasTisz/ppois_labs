## 📚 Документация

Папка `docs/` является артефактом сборки и **генерируется пользователем самостоятельно**. В репозитории хранится только файл настроек `Doxyfile` и исходный код с комментариями в формате Doxygen.

### Гайд по созданию документации:

1. Убедитесь, что в вашей системе установлена утилита Doxygen:
   - **macOS:** `brew install doxygen`
   - **Linux (Ubuntu/Debian):** `sudo apt install doxygen`
   - **Windows:** Скачайте установщик с официального сайта.
2. Откройте терминал и перейдите в директорию первой лабораторной работы:
   ```bash
   cd lab1
   ```
3. Запустите генерацию, передав конфигурационный файл:
   ```bash
   doxygen Doxyfile
   ```
4. Утилита автоматически создаст папку `docs/`. Перейдите в неё и откройте главный файл сайта в браузере:
   ```bash
   open docs/html/index.html
   ```

## Возможности классов

### Polynomial (Многочлен)
- Хранение коэффициентов в векторе с автоматической нормализацией (удаление старших незначащих нулей).
- Перегрузка арифметических операторов: `+`, `-`, `*`, `/` (деление уголком), `+=`, `-=`, `*=`, `/=`.
- Вычисление значения многочлена в точке $P(x)$ через `operator()`.
- Доступ к коэффициентам через `operator[]`.
- Сравнение (`==`, `!=`) и потоковый ввод-вывод (`<<`, `>>`).

### Set<T> (Канторовское множество)
- Хранение уникальных элементов заданного типа.
- Операции над множествами: объединение (`+`), пересечение (`*`), разность (`-`).
- Построение булеана (множества всех подмножеств) с помощью метода `powerSet()`.
- Проверка вхождения, добавление, удаление элементов.
- Потоковый ввод-вывод в формате `{a, b, c}`.

## Сборка

Проект собирается из консоли с использованием **CMake**.

**Linux / macOS:**
```bash
cd lab1
cmake -S . -B build
cmake --build build
```

**Windows (Visual Studio / MSVC):**
```powershell
cd lab1
cmake -S . -B build
cmake --build build --config Release
```

## Запуск консольного приложения

Точка входа и интерактивное меню изолированы в модуле `app/`. После сборки запустите исполняемый файл:

**Linux / macOS:**
```bash
./build/lab1_app
```

**Windows:**
```powershell
.\build\Release\lab1_app.exe
```

## Тестирование

Проект покрыт модульными тестами на базе **Google Test**. Запуск всех тестов выполняется командой:

```bash
./build/lab1_tests
```

## CI/CD

При каждом пуше и Pull Request запускается GitHub Actions workflow (`.github/workflows/ci.yml`), который автоматически:
- выполняет сборку проекта;
- запускает и проверяет все unit-тесты.

Detailed Description

Пользовательский класс, представляющий сведения об авиарейсе.

Служит для демонстрации работы шаблонных сортировок (Задание 1) и в качестве полезной нагрузки вершины графа (Задание 2). Поддерживает полный набор операций сравнения и потоковый ввод-вывод.
